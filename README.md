## Cómo me gusta construir

- Entender el problema antes que elegir la tecnología.
- Diseñar software que se adapte al negocio, no al revés.
- Construir simple antes que construir grande.
- Priorizar claridad, mantenibilidad y sentido real.
- Documentar decisiones para poder mejorar con criterio.
- Usar los datos no solo para medir, sino para tomar mejores decisiones.
